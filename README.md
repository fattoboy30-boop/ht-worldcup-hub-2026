# HT World Cup Hub

**Honiara Today's World Cup Hub** - Your ultimate source for FIFA World Cup 2026 news, fixtures, and free downloads!

![HT Logo](images/HT%20LOGO.jpg)

## About

HT World Cup Hub is a community-driven website created by Honiara Today to keep football fans in Solomon Islands and across the Pacific informed and excited about the FIFA World Cup 2026.

### Features

- ⚽ **Live Countdown** - Watch the countdown to tournament kickoff
- 📰 **Latest News** - Stay updated with World Cup and Solomon Islands football news
- 📅 **Fixtures** - Complete match schedule with filter options
- 📥 **Free Downloads** - Printable schedules, prediction brackets, wallpapers & more
- 🗳️ **Fan Polls** - Vote and share your opinions

## Solomon Islands Focus

Special coverage of the **Solomon Islands Bonitos** including:
- FIFA Series 2026 matches
- Player profiles from Western Province
- Match previews and analysis

## Deployment

1. Fork this repository
2. Go to Settings > Pages
3. Select "main" branch as source
4. Your site will be live at `https://yourusername.github.io/ht-worldcup-hub/`

## Customization

### Update News

Edit `js/data.js` to add new news items:

```javascript
{
    id: 7,
    title: "Your News Title",
    summary: "News summary here",
    tag: "Category",
    date: "March 26, 2026",
    image: "football7.jpg"
}
```

### Update Fixtures

Add new fixtures to the fixtures array in `js/data.js`.

### Add Downloads

Add new download items to the downloads array.
